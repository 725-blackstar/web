# 手势粒子魔法（Hand Magic Particles）

基于 **原生 JavaScript + Three.js + MediaPipe Hands** 的实时交互 3D 粒子系统。通过摄像头识别双手，粒子实时响应手势，可组成文字、扩散、收缩成搏动的爱心。

> 本文档面向人类与 AI 维护者，说明项目的运行方式、技术架构、核心逻辑与修改入口。

---

## 1. 快速运行

任何装有 **Windows**（Win7+，自带 PowerShell）的电脑均可离线运行，**无需安装任何软件**。

1. 拷贝整个文件夹到目标电脑；
2. 双击 **`start.bat`**；
3. 程序自动启动本地 HTTP 服务器（内置 `server.ps1`，保证可用端口自动分配）并在浏览器打开；
4. 浏览器弹出「允许使用摄像头」时点击 **允许**。

> ⚠️ 不要直接双击 `index.html`（`file://` 协议下 Chrome 会禁止调用摄像头）。必须经由 localhost/HTTP 访问，start.bat 已自动处理。

## 2. 交互规则

- 摄像头画面全屏，作为粒子系统背景，Three.js 透明画布叠加其上。
- 用户画面为**镜像**（自拍视角），坐标映射已同步镜像。

### 左手 —— 切换文字造型
| 手势 | 伸出指数 | 粒子形成文字 |
|------|---------|------------|
| 手势1 | 1 指 | `hello` |
| 手势2 | 2 指 | `你好，同学` |
| 手势3 | 3 指 | `欢迎加入网络安全社！` |

- 手势需稳定保持 ≥5 帧才会切换（防抖），握拳或张开手掌保持 ≥5 帧可回到无文字状态。
- **所有状态下，粒子会自动躲避左手所在区域**（以手心为中心、按手部大小确定排斥半径的排斥力）。

### 右手 —— 掌控扩散 / 收缩
- **手掌张开**：粒子扩散到三维球体分布；并根据"手腕→中指"连线角度变化率（角速度）给粒子施加切向力，使粒子群跟随右手旋转方向产生旋转轨迹运动。
- **握拳**：粒子收缩并向屏幕正中心聚拢，生成参数化 3D 爱心；爱心按心跳节律（约 73 bpm、双峰"lub-dub"）周期性搏动，完整可见。

### 模式优先级
```
right 握拳(且检测到)  →  爱心模式（heart）
left  手势 1/2/3      →  文字模式（text）
其余                 →  扩散模式（diffuse）
```
左手躲避排斥在任何模式下均生效。

## 3. 技术栈与资源

| 类别 | 选择 | 说明 |
|------|------|------|
| 3D | Three.js **0.160.0**（ES Module） | 经 `动态 import()` 加载，无需 importmap |
| 手势 | MediaPipe Hands 经典版（`@mediapipe/hands` 0.4.x + `camera_utils`） | 通过普通 `<script>` 加载 |
| 服务器 | PowerShell `server.ps1`（System.Net.Sockets.TcpListener） | 零依赖静态服务器，无 URL ACL 限制 |
| 启动器 | `start.bat` | 双击入口 |

### 资源加载策略
- 默认**全部从本地 `lib/` 加载**，完全离线可用；
- 提供多 CDN 兜底（jsdelivr → unpkg → npmmirror），本地缺失时自动回退网络。

```
手势粒子魔法/
├── index.html          # 单页应用（全部代码在此文件内）
├── start.bat           # 双击启动
├── server.ps1          # HTTP 静态服务器
└── lib/
    ├── three/three.module.js
    └── mediapipe/
        ├── camera_utils/camera_utils.js
        └── hands/                    # 含模型/wasm，运行时通过 locateFile 请求
```

## 4. 代码结构（均在 `index.html` 的 `<script type="module">` 内）

| 区域 | 关键函数/常量 | 职责 |
|------|--------------|------|
| 依赖加载 | `loadThree()`、`loadScript()`、`initMediaPipe()` | 多 CDN 容错加载 |
| Three.js 初始化 | `renderer`、`scene`、`camera` | 相机 z=9.5、fov=55、透明背景 |
| 粒子系统 | 常量 `N = 26000`，并行 `Float32Array` 数组（`px/py/pz` 等） | 提高性能避免 GC |
| 颜色 | `base[]`、调色板 | 粉色与白色混合（约 32% 白色） |
| 文字采样 | `sampleText()`、`getTextPoints()`、`ensureText()` | canvas 绘制→取 alpha 像素→归一化到世界坐标 |
| 爱心采样 | `heartPts[]`、常量 `HWS = 2.4` | 参数方程填充采样 |
| 心跳 | `heartbeat(t)` | 双峰高斯脉冲，周期 0.82s |
| 手势识别 | `fingersExtended()`、`updateHand()`、`onResults()` | 指尖/腕距离判伸展；左手按伸出指数匹配 1/2/3 |
| 主循环 | `updateParticles(dt, t)`、`renderer.setAnimationLoop` | 每小时更新目标→Lerp→游走→涡流→排斥→落位 |

### 单粒子每帧更新流程（`updateParticles`）
1. 依据模式计算目标点 `tx,ty,tz`（文字点 / 爱心跳动点 / 家位置）；
2. 向目标收敛：`pos += (target - pos) * k`（不同模式收敛速度不同，文字最快）；
3. 叠加低频随机游走（扩散后阻尼增强、速度减弱，满足"扩散后运动速度减弱"）；
4. 扩散模式下叠加右手旋转涡流（切向力）；
5. 叠加左手排斥力；
6. 速度阻尼、写入 Position/Color attribute。

## 5. 常用修改入口

| 想改什么 | 位置 |
|---------|------|
| 文字内容 | `TEXT_LIST`（注意：手势 1→1 指对应索引 1，依此类推） |
| 粒子数量 / 大小 | `N` 常量；`PointsMaterial` 的 `size: 0.032` |
| 颜色混合 | `base[]` 初始化处的 `setHSL(...)` 与白色概率 `0.32` |
| 心跳频率 | `heartbeat()` 中周期 `T = 0.82` |
| 爱心大小 | 常量 `HWS` |
| 排斥半径 | `state.left.scale * 4.2` |
| 扩散分布 | `hx/hy/hz` 初始化（`cbrt` 球体均匀分布） |
| 文字字号/采样 | `sampleText()` 中 `size`（英文 230 / 中文 170）与采样步长 `step=2` |
| 服务器端口 | `server.ps1` 使用 TcpListener 端口 0（自动分配），无需修改 |

### 文字/爱心识别原理
- **文字**：离屏 canvas `fillText` → `getImageData` 取 alpha>100 的像素 → 按比例归一化到世界坐标（`fitW=7.2`、`fitH=2.6`）→ 每个粒子随机绑定一个文字点（切换文字时重新洗牌）。
- **爱心**：经典心形参数方程 `x=16sin³t`、`y=13cost-5cos2t-2cos3t-cos4t`，半径因子填充内部，z 向按半径衰减做厚度，得到立体爱心。

### 手势判定细节
- 手指伸展：`指尖到中节(PIP) 距离 > 1.18 × 中节(PIP)到掌指(MCP)距离`（比例法对旋转不敏感），介于 0.92~1.18 时保持上次状态（每指迟滞防抖）；
- 拇指：`拇指尖到食指MCP > 1.35 × 拇指PIP到食指MCP`；
- 右手 开/捂拳：伸出指数 ≥3 → 张开；≤1 → 握拳；连续 2 帧一致才切换；
- 左手伸出指数：连续 2 帧相同才认作新值，稳定 ≥5 帧后落定手势；
- 左右手分配：双手同现时按镜像后屏幕横坐标排序（左半屏 = 左手）；**单手优先生成时按 MediaPipe 左右手标记归属**，仅一只手也可触发对应手势。

## 6. 常见问题排查

| 现象 | 原因/解决 |
|------|----------|
| 摄像头不开 | 必须经 `start.bat`（localhost）打开，并点击授权；`file://` 会被拒 |
| 加载后黑屏/无粒子 | 检查 `lib/` 是否完整；若断网且本地缺失会报错，看控制台 |
| 手势不识别 | 光线充足、手离镜头 0.5~2m；MinGit 无需安装即可跑通（`lib/mediapipe/hands` 模型约 5 MB/个） |
| 想用固定端口 | 修改 `server.ps1` 中 `TcpListener(..., 0)` 的 0 为具体端口即可 |
